# 배틀 시뮬레이터 KR (한국어 포켓몬 배틀 시뮬레이터)

스마트폰에서 바로 하는 한국어 포켓몬 배틀 앱. 배틀 계산은 이 저장소의 **Pokémon Showdown 시뮬레이터(`sim/`)를 그대로** 브라우저에서 돌립니다.

## 받기
- **안드로이드**: [`release/BattleSimKR-v2.2.0.apk`](release/BattleSimKR-v2.2.0.apk) 를 받아 설치 (출처를 알 수 없는 앱 허용 필요, 안드로이드 7.0 이상)
- **저용량판**: [`release/BattleSimKR-lite-v2.2.0.apk`](release/BattleSimKR-lite-v2.2.0.apk) — 그림·울음소리·기술 애니메이션을 앱에 넣지 않고 전부 인터넷에서 받습니다(약 1.5MB, 인터넷 필요). 정식판과 같이 설치할 수 있습니다.
- **아이폰·PC**: `dist/index.html` 한 파일을 브라우저로 열거나 웹에 올리면 됩니다 (홈 화면에 추가 → 앱처럼 실행)
- 포켓몬 그림은 기본이 앱에 들어 있는 정지 도트 그림(오프라인 가능)이고, 설정에서 '움직이는 그림'을 고르면 인터넷에서 3D 움직이는 그림을 받아 씁니다. 거다이맥스하면 거다이맥스 전용 그림.

## 규칙
- **기술 사양은 포켓몬 챔피언스 기준**(`src/ps/champions-moves.json`, Serebii ‘Updated Attacks’): 골드러시 명중 95·특공 2랭크 하락, 빙산바람 위력 120, 베어가르기 80, 임팩트 100, 메테오어설트 170,
  스냅트랩 강철타입, 성장 풀타입, 더블쇼크 필중·펀치, 소금절이 1/16(물·강철 1/8), 독실 스피드 2랭크 하락, 크로스클로·섀도클로·드래곤클로 베기 기술, 밀크드링크 아군 대상 등 32개.
  PP도 챔피언스 방식(PP업 없이 5→8, 10→12, 15→16, 20 이상→20)으로 맞췄습니다. Z기술·다이맥스 기술 위력은 바뀐 위력에서 공식 표대로 다시 계산됩니다(예: 빙산바람 120 → Z 190, 맥스 140). 시뮬레이터와 기술 설명 표시 양쪽에 적용됩니다.
- **능력 포인트(포켓몬 챔피언스 방식)**: 노력치 대신 능력마다 0~32포인트, 합계 66포인트. 개체값은 없고 모두 최대. 레벨 50에서 1포인트 = 능력치 +1.
  (내부적으로는 같은 효과의 노력치로 바꿔 시뮬레이터에 넣음: 첫 1포인트 = 4, 이후 8씩. 기존 팀·쇼다운 텍스트의 노력치는 자동 변환)
- **배틀 규칙(설정)**: 쇼다운처럼 고릅니다. 전국도감 플랫(기본: 초전설·환상 제외, 준전설 가능) / 전국도감 전부 / 기믹 모두, 9세대(테라스탈), 8세대(다이맥스, 8세대까지), 7세대(메가진화+Z기술, 7세대까지),
  6세대(메가진화), 포켓몬 챔피언스 레귤레이션 M-A·M-B·M-C(메가진화 1회, 허용 메가 목록 59/75/81종, 전설·환상 제외), 기믹 없음.
  나와 상대 모두에게 적용되고 무작위·렌탈 팀과 팀 점검 경고도 규칙을 따릅니다. 챔피언스의 정확한 참가 포켓몬 목록은 공개 자료가 그림뿐이라
  '전설·환상(M-A·M-B는 준전설 포함) 제외'로 근사했고, 허용 메가 목록은 공개 자료와 같습니다.
- 메가스톤을 든 포켓몬도 규칙이 허용하면 테라스탈·다이맥스를 쓸 수 있습니다 (쇼다운은 막아 두지만 앱에서 열어 줌).
**9세대 내셔널 도감 기준** (Showdown 의 National Dex 와 같은 방식): 1~9세대 전 포켓몬(1025마리 + 리전폼·메가 등)과 **레전즈 Z-A 의 새 메가진화·메가스톤**, 과거 세대 기술·도구 포함.
**메가진화 · Z기술 · 다이맥스 · 테라스탈**을 모두 쓸 수 있습니다. 단 **한 배틀에 한 종류만**(진영마다) — 예를 들어 다이맥스를 쓰면 그 배틀에서는 테라스탈을 쓸 수 없습니다. 플레이어와 AI 모두 같은 규칙. 레벨 50 (팩토리 오픈 레벨은 100).

## 모드
- 배틀타워(Pt/HGSS 규칙): 도전 시작 때 고른 포켓몬과 순서로 7연전, 상대 엔트리는 볼 수 없고 배틀 사이에 순서를 바꿀 수 없습니다. 배틀팩토리도 빌린 순서대로(교환으로만 바뀜).
- PWT(BW2 규칙)·네임드·프리 배틀: 배틀 전 상대 엔트리를 보고 참가 포켓몬과 순서를 고릅니다(‘이 순서 그대로’로 건너뛰기 가능).
- 배틀팩토리는 Pt/HGSS처럼 직원이 상대 정보를 알려주며 연승할수록 줄어듭니다: 0~6연승 포켓몬 전부 → 7~ 2마리 이름 → 14~ 1마리와 기술 하나 → 21~ 선봉의 기술 하나 → 28~ 주로 쓰는 타입(겹치는 타입이 없으면 ‘타입에 연연하지 않음’).
- 배틀타워는 세트(7연승)마다 상대가 강해집니다: 종족값 400~500 → 560~720, 능력 포인트 55% → 100%, 메가·Z 소지율 ↑, 세트 4부터 준전설, AI 실력 0.55 → 0.97.

팀 편집: 종족(초성 검색)·특성·도구(메가스톤·Z크리스탈 포함)·기술(내셔널 도감 기준 배울 수 있는 기술)·성격·노력치·테라스탈 타입, 추천 세트, 쇼다운 형식 텍스트 가져오기/내보내기.

## 치트 배틀
팀 편집 → 🃏 치트 팀: 아무 기술·특성, 능력 포인트 능력마다 최대 32(합계 제한 없음), 레벨 1~100. 메인 메뉴의 ‘치트 배틀’에서만 쓰이고 전적에 남지 않습니다.

## 상대 AI (`src/ai.ts`)
- **한 턴 내다보기**(실력 '보통' 이상): 배틀 상태를 복제해 내 후보 선택 × 상대 예상 선택을 실제 시뮬레이터로 한 턴 돌려 보고 결과(HP·남은 수·대면 상황)로 고릅니다.
  상대 선택은 같은 휴리스틱으로 예측(상위 2개 가중). 자체 대전에서 이전 AI를 상대로 싱글 3vs3 53%, 6vs6 60%의 승률(각 600판). 더블은 슬롯별 상위 3개 후보 조합 × 상대 예상 선택 3개로 같은 방식(더블 4vs4 53%, 6vs6 58%).
- [Complete-Fire-Red-Upgrade](https://github.com/Skeli789/Complete-Fire-Red-Upgrade) (Skeli789) Battle AI 구조를 옮김:
  모든 기술 viability 100에서 시작 → 실패·무의미한 기술 감점(ai_negatives) → 쓰러뜨릴 수 있는 기술·가장 강한 기술 가점(TryToFaint)
  → 상황별 변화 기술 가점(ai_positives) → 더블 점수표(두 마리 공격·KO 수·같은 편 피해) → 교체 판단(ai_switching: 멸망의노래,
  원더가드, 쓸 기술 없음, 흡수 특성 동료, 자연회복+잠듦, 하품, 지속 피해, 죽음 회피, 공격 능력 크게 하락)과 가장 적합한 교체 대상 선택.
  CFRU 는 비영리 사용 조건이므로 이 앱도 **비영리**로만 배포합니다.
- 기믹 판단(CFRU ShouldAIDynamax 방식): "결과가 바뀔 때"만 씁니다 — 쓰면 이번 턴에 쓰러뜨릴 수 있게 되는가, 쓰면 상대의 예상 공격을 버티는가,
  남은 포켓몬이 적고 이 포켓몬이 팀의 에이스인가를 점수로 계산해 기준을 넘을 때만. 한 종류만 쓸 수 있으므로 에이스를 위해 아껴 둡니다.
  테라스탈은 테라 후 새로 생기는 약점을 상대가 찌를 수 있으면 감점. 실력이 낮은 AI 는 가끔 아무렇게나 씁니다.
- [FredodaFred/pokemon-battle-ai](https://github.com/FredodaFred/pokemon-battle-ai) 의 규칙 기반 점수(추가효과·자해 고려) 아이디어 반영.
- [atw1020/Pokemon_Battle_AI](https://github.com/atw1020/Pokemon_Battle_AI) 는 학습된 모델이 필요한 TensorFlow 신경망이고, 저자 README에 따르면 정확도가 50% 수준이라 사용하지 않았습니다.
- 데미지는 실제 능력치(노력치·성격·랭크)로 계산하고, 난이도(skill)가 낮을수록 실수가 잦아집니다.

## 트레이너 · 연출 · 소리
- 트레이너 스프라이트: Showdown 스프라이트 서버(포켓몬 그림과 같은 곳)에서 실행 중에 불러옵니다. 네임드 트레이너 117명(관동~팔데아·블루베리). 한국어 이름은 나무위키 체육관 관장·사천왕 문서와 대조(모든 이름 대조 완료) + 일반 트레이너 직업 27종(남/여) + 타워 타이쿤·팩토리 헤드, 주인공 모습 21종(역대 주인공) 선택.
- 대사(`src/trainer-lines.ts`): 승부 시작 · 마지막 포켓몬을 낼 때 · 이겼을 때 · 졌을 때. 모두 이 앱을 위해 새로 쓴 대사입니다.
- 배틀 시작 시 양쪽 트레이너가 발판에 등장 → 대사 → 포켓몬 등장, 상대 마지막 포켓몬 때 트레이너 재등장, 승부 후 트레이너 대사.
- **기술 애니메이션: Pokémon Reborn 팀 제작 애니메이션 925종**(PokéRogue 에셋 저장소에서 변환, CC BY-NC-SA 4.0, `public/anims/CREDITS.md`).
  `scripts/import-anims.py` 로 변환 — 기술마다 다른 그림·효과음·배경, 사용자/대상 스프라이트 움직임 포함. 애니메이션이 없는 기술은 아래 자체 연출로.
- 다이맥스·거다이맥스 기술은 전용 대형 연출(기운 모으기 → 거대 구체 → 폭발·빛기둥·화면 흔들림).
- 자체 기술 이펙트(`src/fx.ts`): 연출 원형 19종(빔·번개·탄·줄기·베기·타격·지진·파도·낙하·소용돌이·폭발·가루·음표·방패·흡수·물기·초승달·투척·반짝이)을
  기술 이름·타입·분류·위력으로 조합해 기술마다 다른 연출 (예: 지진=땅 흔들림, 10만볼트=번개, 화염방사=불줄기, 하이퍼빔=빔, 스톤에지=낙석, 크런치=물기,
  리프블레이드=베기, 날개치기=초승달, 버섯포자=가루, 노래=음표, 방어=방패, 기가드레인=흡수). 타격 시점에 맞춰 타격음 재생.

  (PokeRogue 등의 음원은 대부분 공식 게임에서 추출된 것이라 이 저장소에는 넣지 않았습니다 — 쓰려면 본인 판단으로 파일만 넣으면 됩니다).
- 배틀 음악은 배틀 1·2·3, 시설, 토너먼트, 보스 6곡 중 상황에 맞게 무작위로 흐르며 설정에서 고정할 수도 있습니다. 울음·효과음 / 기술 효과음(끔·작게·보통·크게, 기본 작게) / 음악 음량을 따로 조절.
- 앱이 뒤로 가거나 화면을 끄면 소리가 모두 멈추고, 돌아오면 이어집니다. 설정에서 효과음·배경음악을 따로 끌 수 있습니다.
- 설정: 창틀 디자인(돌·은·어두움), 메뉴 배경(6종), 주인공 모습, 메시지 속도(매우 빠름 포함), 진동(효과 굉장·급소·기절), 기술 이펙트·데미지 예상 켜기/끄기.
- 기술 애니메이션 효과음은 Reborn 애니메이션에 딸린 것을 쓰며, 설정의 효과음 음량을 따릅니다. 울음소리·효과음 기본 음량은 "낮음"입니다(기존 사용자도 한 번 낮음으로 맞춰짐).

- 네임드 트레이너 189명(엔트리의 미진화체는 최종 진화형이나 어울리는 완전진화체로 교체): 관장·사천왕·챔피언 117명 + 역대 주인공·라이벌·악의 조직 간부/보스 72명(로켓단·마그마단·아쿠아단·갤럭시단·플라스마단·플레어단·스컬단·에테르재단·로즈·스타단 등).
  대사는 나무위키(namu.moe 미러)의 한국어판 대사를 바탕으로 정리하고, 기록이 없는 칸은 인물 말투에 맞춰 보충(`src/trainer-lore.ts`, 출처 표시 포함). 배틀타워 7연승 특별 트레이너에도 등장.
- 울음소리 1,025종을 앱에 포함(오프라인 재생, 없는 폼은 기본 모습 울음소리).

## 배틀 계산기
메인 메뉴의 배틀 계산기: 공격/방어 포켓몬(저장된 팀의 세트 또는 종족 검색 → 추천 세트, 세트 편집 가능)·기술·랭크·상태이상·테라스탈·날씨·필드·벽·급소·도우미를 넣으면
9세대 계산식(범위→날씨→급소→16난수→자속→상성→화상→기타)으로 데미지 범위·HP 비율·확정/난수 n타를 계산합니다. 스피드 탭은 랭크·마비·구애스카프를 반영해 선공을 비교합니다.
주요 특성·도구(구애·생명의구슬·달인의띠·진화의휘석·돌격조끼·천하장사·근성·테크니션·우격다짐·적응력·색안경·두꺼운지방·필터·멀티스케일 등)를 반영하고 미반영 항목은 결과에 표시합니다.

## 배틀 중 정보
- 필드 버튼(명령창·화면 오른쪽 위): 날씨·필드·트릭룸 등의 남은 턴, 양쪽의 스텔스록·압정·벽(오로라베일 등)과 남은 턴, 각 포켓몬의 상태이상·지속 효과.
- 날씨·필드는 배틀 화면에 표시됩니다: 비·강한 비(시작의바다)·쾌청·강한 햇살(끝의대지, 열기 일렁임)·모래바람·눈·난기류(델타스트림), 일렉트릭·그래스·미스트·사이코필드(바닥 그라데이션, 입자 없음). 필드는 한 번에 하나만. 끝의대지의 열기 입자는 아주 느리게.
- 상대 포켓몬을 누르면 약점·반감·사용한 기술, 그리고 배틀 중 드러난 특성·도구(드러나기 전엔 '미확인'과 특성 후보)가 보입니다. 설정의 "데미지 예상"을 켜면 기술 버튼에 예상 데미지 비율이 표시됩니다.

- 기술 정보에 우선도·접촉 여부 표시, PP가 적으면 빨간색. 더블에서 공격 가능한 상대가 하나면 자동 선택.
- 상대 포켓몬 정보에 내 포켓몬과의 스피드 범위 비교. 배틀 로그 복사 버튼. 배틀 중 화면 꺼짐 방지.
- 부활의기원(Revival Blessing) 사용 시 기절한 포켓몬만 고르도록 처리(UI·AI 모두). 배틀 종료 시 턴 수·남은 포켓몬 표시.

## 팀 편집
- 쇼다운 텍스트(영어/한글) 여러 마리 한 번에 가져오기(테라타입·거다이맥스·색 포함), 내보내기, 팀 복제.
- 포켓몬 그림은 정지 도트 그림의 아래 투명 여백을 미리 재어(`src/gen/sprite-pad.json`, `scripts/sprite-pad.py`) 발판에 정확히 서도록 맞춥니다.
- 세트 편집의 모습·성별·볼·성격·테라타입은 드롭다운으로 고릅니다. 치트 팀에서는 메가·원시회귀·거다이맥스 같은 배틀 중 모습도 고를 수 있습니다.
- 세트 편집 맨 위 ‘모습’ 줄에서 같은 포켓몬의 다른 모습(로토무 5종, 알로라·가라르·히스이·팔데아 모습, 데오키스·오리진 폼 등)을 고를 수 있습니다. 모습을 바꾸면 특성·테라타입이 맞춰집니다.
- 세트 편집에서 성별(종족 성별비에 맞는 것만)과 몬스터볼(28종, 등장 때 볼 색·빛·입자가 달라짐)을 고를 수 있고, 텍스트 가져오기의 `(M)/(F)`·`Ball:` 도 읽습니다.
- 거다이맥스 가능한 포켓몬은 세트 편집에서 체크 (다이맥스 규칙에서 거다이맥스 모습·G맥스 기술). 무작위 팀도 60% 확률로 켜짐.
- 팀 점검: 도구 중복·같은 포켓몬·기술 없음·메가스톤 2개 이상·맞지 않는 메가스톤·구애 도구/돌격조끼+변화기 등 경고.
- 팀 분석: 타입별 약점/반감 수, 공격 기술 타입 커버리지.
- 능력 포인트 프리셋·±버튼, 자동 배분은 66포인트를 모두 씀. 기술 순서 ▲▼ 버튼으로 바꾸기, ✕로 빼기. 포켓몬 정렬(도감·가나다·종족값·공격력·스피드)과 타입 필터.
- 기술 고르기: 가나다·위력·타입·명중·PP 정렬, 물리/특수/변화·타입 필터, 분류 아이콘. 도구 고르기: 자주 쓰는 순·가나다 정렬, 분류 필터, 도구 아이콘.
- 팀 고르기 화면에서 최근 사용한 팀이 맨 위. 타워·팩토리 진행 화면에서 내 포켓몬을 눌러 상세 보기. 홈·기록에 승률 표시.

- 배틀 화면 오른쪽 위 ☰ 메뉴: 배틀 기록·필드·배속·기권·메인 메뉴로(끝나지 않은 배틀은 패배로 기록, 연승 도전 종료). 안드로이드 뒤로 버튼도 이 메뉴를 엶.
- 배틀 화면 오른쪽 위 배속 버튼(×0.5 / ×1 / ×2 / ×4, 빨리감기는 배속으로 통합): 메시지·기술 애니메이션·볼·기절·HP 바 등 모든 연출 속도를 바로 바꿈. 짧은 메시지는 더 빨리 넘어감.
- 기술 버튼은 원작처럼 기술마다 한 칸(타입 색, 타입·물리/특수/변화 아이콘, PP, 상성 표시). 길게 누르면 위력·명중·우선도·접촉·설명.
- 포켓몬 그림은 배틀 시작 때 미리 받아 두어 교체·메가진화 때 늦게 뜨지 않음.

- 화면 디자인: 도트 글꼴·도트 그림은 유지하고, 창·버튼·배틀 메뉴는 원작 포켓몬 게임처럼(큰 ‘싸운다’ 버튼, 타입 색 기술 버튼, 둥근 정보 상자) CSS로 새로 그림. 창틀 색 블루·레드·블랙.
- 일부 도트 장식: [Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon) 의 `chrome.png` (GPL-3.0, `src/ui-assets/LICENSE-SPD-GPL3.txt`)
- 도구 아이콘: Showdown 아이템 아이콘 시트를 실행 중에 불러옴.
- 글꼴: [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1, `src/fonts/OFL-Galmuri.md`)

## 빌드
- 저용량판: `node battle-kr/build.mjs --lite --android` → 그림·울음소리·애니메이션을 빼고 `android/app/src/lite/assets` 로, 애니메이션은 jsDelivr(저장소의 public/anims, 마지막 변경 커밋 고정)에서 받음. `./gradlew assembleLiteRelease` / 정식판은 `assembleFullRelease`.
- **오프라인 그림**: `bash battle-kr/scripts/fetch-sprites.sh` 로 포켓몬(정지 그림 앞/뒤·색이 다른 모습, 약 1,300종 × 4), 트레이너, 대타 인형, 도구 아이콘을
  `public/sprites/` 에 받아 두면 빌드할 때 앱에 들어갑니다(약 22MB, 저장소에는 올리지 않음). 인터넷이 되면 움직이는 그림을, 안 되면 앱 안의 그림을 씁니다.
```
npm ci --omit=optional          # 저장소 루트
node build                      # dist/ (시뮬레이터 컴파일)
node battle-kr/scripts/gen-data.cjs   # 한글 데이터 → src/gen/dex.json
node battle-kr/build.mjs        # → battle-kr/dist/index.html (한 파일, 약 4.5MB)
node battle-kr/build.mjs --android && cd battle-kr/android && ./gradlew assembleRelease
```
- 안드로이드 SDK 경로는 `android/local.properties` 의 `sdk.dir`.
- 서명: 환경변수 `BATTLESIM_KEYSTORE`(키스토어 경로, 별칭 `battlesim`)·`BATTLESIM_KEY_PASSWORD` 를 주면 그 키로, 없으면 디버그 키로 서명합니다. 키는 저장소에 넣지 마세요 (같은 키로 서명해야 업데이트 설치 가능).
- GitHub Actions `배틀 시뮬레이터 APK` 워크플로가 APK·웹 파일을 아티팩트로 만듭니다.
- AI 자체 대전 테스트: `node battle-kr/build.mjs --test` → `test/selfplay.html` 을 열고 `selfplay(25, 9, false, 0.95, 0.3)` (기믹 사용 횟수도 표시).
