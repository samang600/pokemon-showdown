# 배틀 시뮬레이터 KR (한국어 포켓몬 배틀 시뮬레이터)

스마트폰에서 바로 하는 한국어 포켓몬 배틀 앱. 배틀 계산은 이 저장소의 **Pokémon Showdown 시뮬레이터(`sim/`)를 그대로** 브라우저에서 돌립니다.

## 받기
- **안드로이드**: [`release/BattleSimKR-v2.31.0.apk`](release/BattleSimKR-v2.31.0.apk) (약 2MB, 칩튠 배경음악 포함) 를 받아 설치 (출처를 알 수 없는 앱 허용 필요, 안드로이드 7.0 이상)
- 그림·울음소리·기술 애니메이션은 기본적으로 인터넷에서 그때그때 받습니다. **설정 → 오프라인 데이터 → 한 번에 받기**(약 24MB 내려받기, 풀면 약 60MB)를 누르면 앱 저장소에 받아 두어 인터넷 없이도 모두 나옵니다.
- **아이폰·PC**: `dist/index.html` 한 파일을 브라우저로 열거나 웹에 올리면 됩니다 (홈 화면에 추가 → 앱처럼 실행)
- 포켓몬 그림은 기본이 정지 도트 그림(오프라인 데이터를 받아 두면 인터넷 없이도)이고, 설정에서 '움직이는 그림'을 고르면 인터넷에서 3D 움직이는 그림을 받아 씁니다. 거다이맥스하면 거다이맥스 전용 그림.

- **PC**: 같은 웹 빌드(`dist/index.html`, PWA)를 PC 브라우저에서 열면 가로 화면 배치로 바뀝니다 — 왼쪽 큰 배틀 필드, 오른쪽 조작 패널. 키보드: 숫자 1~6 = 기술·교체·대상 고르기, Enter/Space = 싸운다·메시지 넘기기, Esc/Backspace = 뒤로·창 닫기.

## 규칙
- **기술 사양은 포켓몬 챔피언스 기준**(`src/ps/champions-moves.json`, Serebii ‘Updated Attacks’): 골드러시 명중 95·특공 2랭크 하락, 빙산바람 위력 120, 베어가르기 80, 임팩트 100, 메테오어설트 170,
  스냅트랩 강철타입, 성장 풀타입, 더블쇼크 필중·펀치, 소금절이 1/16(물·강철 1/8), 독실 스피드 2랭크 하락, 크로스클로·섀도클로·드래곤클로 베기 기술, 밀크드링크 아군 대상 등 32개.
  PP도 챔피언스 방식(PP업 없이 5→8, 10→12, 15→16, 20 이상→20)으로 맞췄습니다. Z기술·다이맥스 기술 위력은 바뀐 위력에서 공식 표대로 다시 계산됩니다(예: 빙산바람 120 → Z 190, 맥스 140). 시뮬레이터와 기술 설명 표시 양쪽에 적용됩니다.
- **Showdown 의 champions 모드도 함께 적용**: 위력·명중(블러드문 130, 트리플다이브 35, 하이퍼드릴 120, 앵커샷 90, 드래곤해머 100, 아가미물기·전격부리 80, 기어소서 60/90, 소울비트 필중 등), PP(방어 계열·희망사항·모래바람·설경 등), 프리즈드라이 얼음 효과 없음, 속이다·기습 등 첫 턴 제한, 앙코르·사슬묶기·저주·배수의진 동작.
  특성: 재생력·자연회복·치유의마음·보이지않는주먹·도주·분노의껍질·발끈·위기회피·도망태세. (기술 설명 화면의 위력·명중·PP 도 같은 값)
- **배울 수 있는 기술**: 모든 규칙에서 본가 전 세대 목록 + Showdown champions 모드의 기술 목록(포켓몬 챔피언스 기준, 예: 아쿠스타 아쿠아제트·아쿠아브레이크)을 합친 것. 로토무 폼처럼 폼 체인지하는 포켓몬은 원래 모습의 기술도 모두 배움.
- **상태이상도 포켓몬 챔피언스 기준**(Showdown 의 champions 모드와 같음): 마비로 못 움직일 확률 1/8(본가 1/4), 잠듦 2~3턴(2턴째에 깰 확률 1/3, 본가 1~3턴), 얼음 최대 3턴·매 턴 1/4 로 녹음(본가 1/5·상한 없음).
  화상 1/16·독 1/8·맹독 n/16·씨뿌리기 1/8 등 지속 데미지는 본가와 같음.
- **능력 포인트(포켓몬 챔피언스 방식)**: 노력치 대신 능력마다 0~32포인트, 합계 66포인트. 개체값은 없고 모두 최대. 레벨 50에서 1포인트 = 능력치 +1.
  설정의 **노력치 표시**로 본가 노력치 단위(0·4·12…252)로도 볼 수 있습니다(1포인트 = 처음 4, 이후 8). 규칙은 그대로 66포인트라 본가 510(=65포인트)보다 1포인트(노력치 8) 많으며(예: 252/252/12),
  노력치 방식으로 내보낸 텍스트는 합계 510에 맞추고, 본가 노력치를 꽉 채운 세트(예: 252/252/4)를 가져오면 남는 1포인트를 4를 준 능력에 더합니다(→ 32/32/2).
  (내부적으로는 같은 효과의 노력치로 바꿔 시뮬레이터에 넣음: 첫 1포인트 = 4, 이후 8씩. 기존 팀·쇼다운 텍스트의 노력치는 자동 변환)
- **배틀 규칙(설정)**: 쇼다운처럼 고릅니다. 룰 플랫(기본: 초전설·환상 제외, 준전설 가능) / 전부 / 기믹 모두(종류마다 1회, 단 한 포켓몬은 기믹 하나만 — 다이맥스 중 테라스탈 등 불가), 무제한(전설·환상 포함, 상대도 전설·환상을 데려옴, 기믹 종류마다 1회에 한 포켓몬이 겹쳐 쓰기 가능 — 메가진화·원시회귀한 포켓몬의 테라스탈만 불가), 9세대(테라스탈), 8세대(다이맥스, 8세대까지), 7세대(메가진화+Z기술, 7세대까지),
  6세대(메가진화), 포켓몬 챔피언스 레귤레이션 M-A·M-B·M-C(메가진화 1회, 허용 메가 목록 59/75/81종, 전설·환상 제외), 기믹 없음.
  나와 상대 모두에게 적용되고 무작위·렌탈 팀과 팀 점검 경고도 규칙을 따릅니다. 챔피언스의 정확한 참가 포켓몬 목록은 공개 자료가 그림뿐이라
  '전설·환상(M-A·M-B는 준전설 포함) 제외'로 근사했고, 허용 메가 목록은 공개 자료와 같습니다.
- 메가스톤을 든 포켓몬도 규칙이 허용하면 테라스탈·다이맥스를 쓸 수 있습니다 (쇼다운은 막아 두지만 앱에서 열어 줌).
**9세대 내셔널 도감 기준** (Showdown 의 National Dex 와 같은 방식): 1~9세대 전 포켓몬(1025마리 + 리전폼·메가 등)과 **레전즈 Z-A 의 새 메가진화·메가스톤**, 과거 세대 기술·도구 포함.
**메가진화 · Z기술 · 다이맥스 · 테라스탈**을 모두 쓸 수 있습니다. 단 **한 배틀에 한 종류만**(진영마다) — 예를 들어 다이맥스를 쓰면 그 배틀에서는 테라스탈을 쓸 수 없습니다. 플레이어와 AI 모두 같은 규칙. 레벨 50 (팩토리 오픈 레벨은 100).

## 모드
- 배틀타워·배틀팩토리 형식: 싱글 3vs3 / 더블 4vs4 / 싱글 6vs6 / 더블 6vs6, 배틀타워는 **멀티배틀**도(파트너 트레이너와 2마리씩, 상대 트레이너 2명과 더블배틀 — 내 포켓몬은 내가, 파트너 포켓몬은 파트너 AI가 지시하고 교체도 각자 자기 포켓몬만. 메가진화·Z기술·다이맥스·테라스탈 등 기믹 횟수도 나와 파트너가 따로 셈 — 같은 턴에 각자 써도 됨). (상대를 보고 4마리를 고르는 챔피언스식 6→4 는 랭크 매치에 있습니다) ‘도전 그만두기’는 한 번 더 확인합니다(‘쉬기’는 저장 후 나가기).
- 배틀타워(Pt/HGSS 규칙): 도전 시작 때 고른 포켓몬과 순서로 7연전, 상대 엔트리는 볼 수 없고 배틀 사이에 순서를 바꿀 수 없습니다. 7연승(세트 클리어)마다 팀을 바꾸거나(연승 유지) 저장하고 쉴 수 있습니다. 배틀팩토리도 빌린 순서대로(교환으로만 바뀜).
- PWT(BW2 규칙)·네임드·프리 배틀: 배틀 전 상대 엔트리를 보고 참가 포켓몬과 순서를 고릅니다(‘이 순서 그대로’로 건너뛰기 가능).
- 배틀팩토리는 Pt/HGSS처럼 직원이 상대 정보를 알려주며 연승할수록 줄어듭니다: 0~6연승 포켓몬 전부 → 7~ 2마리 이름 → 14~ 1마리와 기술 하나 → 21~ 선봉의 기술 하나 → 28~ 주로 쓰는 타입(겹치는 타입이 없으면 ‘타입에 연연하지 않음’).
- 배틀타워는 세트(7연승)마다 상대가 강해집니다: 종족값 400~500 → 560~720, 능력 포인트 55% → 100%, 메가·Z 소지율 ↑, 세트 4부터 준전설, AI 실력 0.55 → 0.97.
- **난이도**(배틀타워·배틀팩토리 형식 선택 화면): 쉬움 / 보통 / 어려움. 보통이 기본(위 설명대로). 쉬움은 처음 두 세트 상대가 미진화·중간 진화 포켓몬을 쓰고 이후로도 두 세트 늦게 강해짐(준전설 등장도 늦음), 어려움은 처음부터 세 세트 앞선 강함(팩토리는 렌탈·상대 등급도 함께 이동). 난이도마다 도전 저장과 최고 연승 기록이 따로입니다.
- 다음 상대는 정해지는 순간 저장되어, 승부 전 화면에서 쉬었다가 다시 와도(앱을 껐다 켜도) 같은 트레이너·같은 엔트리가 나옵니다(네임드 트레이너 포함).
- **배틀 음악 선택**: 형식 선택 화면과 승부 전 화면(타워·팩토리·네임드)에서 배틀 음악을 고르고 바로 미리 들을 수 있습니다. 상황에 맞게 / 무작위(모든 배틀 곡 중) / 없음 / 곡 지정.

## 배틀 옵션 (모드마다 체크박스)
배틀타워·배틀팩토리·PWT·네임드 트레이너·프리 배틀의 형식 선택 화면에서 체크합니다.
- **🃏 치트 팀 허용**: 팀 편집 → 🃏 치트 팀(아무 기술·특성, 능력 포인트 능력마다 최대 32에 합계 제한 없음, 레벨 1~100)을 고를 수 있습니다. 전적·연승에 반영되지 않습니다. (렌탈만 쓰는 배틀팩토리·렌탈 대회에는 없음)
- **레벨 100**: 나와 상대 모두 레벨 100. (배틀팩토리는 자체 레벨 선택을 씀)

## 배틀 계산기
메인 메뉴의 배틀 계산기: 공격/방어 포켓몬(저장된 팀의 세트 또는 종족 검색 → 추천 세트, 세트 편집 가능)·기술·랭크·상태이상·테라스탈·날씨·필드·벽·급소·도우미를 넣으면
9세대 계산식(범위→날씨→급소→16난수→자속→상성→화상→기타)으로 데미지 범위·HP 비율·확정/난수 n타를 계산합니다. 스피드 탭은 랭크·마비·구애스카프를 반영해 선공을 비교합니다.
주요 특성·도구(구애·생명의구슬·달인의띠·진화의휘석·돌격조끼·천하장사·근성·테크니션·우격다짐·적응력·색안경·두꺼운지방·필터·멀티스케일 등)를 반영하고 미반영 항목은 결과에 표시합니다.

## 배틀 중 정보
- 필드 버튼(명령창·화면 오른쪽 위): 날씨·필드·트릭룸 등의 남은 턴, 양쪽의 스텔스록·압정·벽(오로라베일 등)과 남은 턴, 각 포켓몬의 상태이상·지속 효과.
- 날씨·필드는 배틀 화면에 표시됩니다: 비·강한 비(시작의바다)·쾌청·강한 햇살(끝의대지, 열기 일렁임)·모래바람·눈·난기류(델타스트림), 일렉트릭·그래스·미스트·사이코필드(바닥 그라데이션, 입자 없음). 필드는 한 번에 하나만. 끝의대지의 열기 입자는 아주 느리게.

## 빌드
- 기본 빌드는 저용량판(그림·울음소리·애니메이션 미포함). 애니메이션은 jsDelivr(저장소의 public/anims, 마지막 변경 커밋 고정)에서, 오프라인 묶음은 `offline/*.zip`(`scripts/make-offline-zips.py`, 현재 브랜치의 raw.githubusercontent.com 주소)에서 받음.
- `node battle-kr/build.mjs --full --android` 로 만들면 그림 등이 앱에 포함된 묶음판(약 30MB)이 됩니다.
- **오프라인 그림**: `bash battle-kr/scripts/fetch-sprites.sh` 로 포켓몬(정지 그림 앞/뒤·색이 다른 모습, 약 1,300종 × 4), 트레이너, 대타 인형, 도구 아이콘을
  `public/sprites/` 에 받아 두면 빌드할 때 앱에 들어갑니다(약 22MB, 저장소에는 올리지 않음). 인터넷이 되면 움직이는 그림을, 안 되면 앱 안의 그림을 씁니다.
```
npm ci --omit=optional          # 저장소 루트
node build                      # dist/ (시뮬레이터 컴파일)
node battle-kr/scripts/gen-data.cjs   # 한글 데이터 → src/gen/dex.json
node battle-kr/build.mjs        # → battle-kr/dist/index.html (한 파일, 약 4.5MB)
node battle-kr/build.mjs --android && cd battle-kr/android && ./gradlew assembleRelease
```
- 안드로이드 SDK 경로는 `android/local.properties` 의 `sdk.dir`.
- 서명: 환경변수 `BATTLESIM_KEYSTORE`(키스토어 경로, 별칭 `battlesim`)·`BATTLESIM_KEY_PASSWORD` 를 주면 그 키로, 없으면 디버그 키로 서명합니다. 키는 저장소에 넣지 마세요 (같은 키로 서명해야 업데이트 설치 가능).
- GitHub Actions `배틀 시뮬레이터 APK` 워크플로가 APK·웹 파일을 아티팩트로 만듭니다.
- AI 자체 대전 테스트: `node battle-kr/build.mjs --test` → `test/selfplay.html` 을 열고 `selfplay(25, 9, false, 0.95, 0.3)` (기믹 사용 횟수도 표시).

## 구조
- `src/ps/` 시뮬레이터를 브라우저에서 돌리기 위한 대체 모듈(fs·path·동적 require 레지스트리, 포맷 목록)
- `src/engine.ts` 플레이어 ↔ AI 대전 진행, `src/text.ts` 프로토콜 → 한국어 메시지(조사 처리 `src/josa.ts`)
- `src/sets.ts` 세트 생성(랜덤배틀 세트 + 자동 세트, 노력치·성격), `src/trainers.ts` 트레이너·대회
- `src/modes.tsx` 모드 진행, `src/ui/` 화면
